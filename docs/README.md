# Packaging documentation

Start with the [release and CD acceptance runbook](https://github.com/komawm/packaging/blob/main/docs/release.md)
for immutable source provenance, isolated package validation, scoped future
credentials, and licensing boundaries. Target template guides cover
[Arch Linux](https://github.com/komawm/packaging/blob/main/archlinux/README.md),
[Debian / Ubuntu](https://github.com/komawm/packaging/blob/main/debian/README.md),
[Fedora / RPM](https://github.com/komawm/packaging/blob/main/rpm/README.md),
[Alpine Linux](https://github.com/komawm/packaging/blob/main/alpine/README.md),
[Nix / NixOS](https://github.com/komawm/packaging/blob/main/nix/README.md),
[FreeBSD 15+](https://github.com/komawm/packaging/blob/main/freebsd/README.md),
and [Homebrew on Linux](https://github.com/komawm/packaging/blob/main/homebrew/README.md).
[VM testing](https://github.com/komawm/packaging/blob/main/docs/vm-testing.md)
documents the headless QEMU/KVM install/launch/removal harness and its results.
Canonical product specifications remain in [koma-docs](https://github.com/komawm/docs).
