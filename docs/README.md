# Packaging documentation

Start with the [release and CD acceptance runbook](https://github.com/komawm/packaging/blob/main/docs/release.md)
for immutable source provenance, isolated package validation, scoped future
credentials, and licensing boundaries. The [Arch template guide](https://github.com/komawm/packaging/blob/main/archlinux/README.md)
describes the initial unaccepted target. Canonical product specifications remain
in [koma-docs](https://github.com/komawm/docs).
